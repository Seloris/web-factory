# two-components

The plugin's test project. Open Claude Code here with the `factory` plugin installed to try the workflow on a stack that cannot fail: `/factory:write-plan demo`, `/factory:implement …`. The plugin's own tests (`node --test plugins/factory/tests` from the repository root) read this project's manifest and run the hooks against it.

`.planning/features/demo/00_spec.md` is a sample spec to plan from.
