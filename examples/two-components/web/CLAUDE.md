# web — the fake front component

```component
kind: front
stack: fake
layers: [data, pages, ui]
commands:
  build: node scripts/echo.mjs build web
  lint: node scripts/echo.mjs lint web {files}
  prepare: node scripts/echo.mjs prepare web
logins: .claude/local/test-logins.md
```

## Conventions

- `data/` talks to the API client generated by `prepare`; `pages/` are routed; `ui/` holds dumb components.
- No unit tests on the front.
