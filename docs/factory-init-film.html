01 Le déroulé
Cinq étapes, une seule fois
1RegarderCe qui se constate ne se demande pas : branches git, dossiers, package.json, CLAUDE.md existants, packs disponibles.
2InterrogerFormat grill-me : questions numérotées, chacune avec sa réponse recommandée. « Oui » l'accepte. 7 au plus par round.
3ÉcrireLes templates remplis : factory.yaml, les CLAUDE.md, .planning/, settings, et le squelette du pack quand le dossier est vide.
4Vérifiermanifest.mjs résout le manifeste, puis build et test doivent passer avec le squelette seul.
5CommiterUn commit tools(tooling): factory init, sur ton oui. Jamais poussé.
Dossier vide ? git init sur la branche de base, puis tout le reste.
Projet déjà monté :component {nom}models {preset}skin {composant} {skin}stack {composant} {stack}
