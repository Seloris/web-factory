# editorial

Paper and ink. A large italic serif title, body text in a reading serif, hairline rules instead of cards, no shadow, one wine-red accent. The page reads like a well-set printed page.

**Fonts:** Fraunces (italic and roman, optical sizes, 400–600) for the title and dialog headings; Newsreader (400–500) for the body; fallbacks `Georgia, serif`.

**Do**
- No panel: content sits on the page (`--panel-bg: transparent`), structured by rules: a strong top rule over lists, a hairline under each row.
- Labels and tags in small spaced capitals; tags as plain accent-colored words, never pills.
- Let the title breathe: it is the page's one display moment.

**Avoid**
- Rounded corners, shadows, filled badges, icons used as decoration.
- Sans-serif text anywhere but code.
