# modern

The default. White surfaces on a faintly cool page, soft layered shadows, plenty of air, one indigo accent. What a carefully made application looks like when it takes no particular stance.

**Fonts:** Geist (400–700) for everything; fallback `ui-sans-serif, system-ui, sans-serif`.

**Do**
- One panel per page, rows as light cards inside it, generous gaps (24–32px between groups).
- The accent only on the primary action, the checked state and the focus ring.
- Title in sentence case, tight tracking; secondary text in `--text-muted`.

**Avoid**
- Several accent colors, gradients, heavy shadows.
- Borders and shadows on the same element beyond the recipes' (a row has its border and a barely visible shadow, nothing more).
