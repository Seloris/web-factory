# Roadmap

What the plugin does not do yet, in the order it is likely to come.

## Stabilisation

Once the workflow stops moving, the marketplace is added from GitHub rather than from a folder, and projects keep their `settings.json` as it is but for the marketplace's source.

## Set aside

- **`factory-helper`**, the pane that drew the workflow (a plan's timeline, the prompt of the next step, a compliance score), is set aside until the workflow settles. Its code and its spec were last present in `b794003`.
